ASP2D Mod 开发工具

    
这是一个纯前端、单文件的 data.js 可视化编辑器。用于修改 Asaka Straight Project 2D 游戏数据。


    
基本流程

    
    
      
  • 点击顶部 「📂 打开 data.js」，选择你项目里的 data.js 文件。
    • 
      
  • 左侧选择 数据类别（武器 / 弹药 / 护甲 …）。
    • 
      
  • 中间列表选择具体条目，右侧表单编辑。
    • 
      
  • 修改会自动保存在内存中；随时可点 「👁 源码预览」 查看生成结果。
    • 
      
  • 点击 「💾 导出 data.js」 下载新文件，替换项目里的 data.js 即可。
    • 
    


    
校验与提示

    
每次编辑都会做实时校验：

    
    
      
  • 必填字段（红点标记）为空会红框提示。
    • 
      
  • ID 冲突（同一类别里 ID 重复）会给出错误提示，无法正常导出。
    • 
      
  • 数值越界（比如穿透 > 10、射速为负数）会给黄色警告，但仍可导出。
    • 
      
  • 每个字段下方会显示一行小提示，说明该字段的常规取值参考。
    • 
    


    
数据类别

    
    
      
  • 基础数据：config、assets、hitZones、damageModel、rarity、valueTable
    • 
      
  • 武器系统：weapons、ammoTypes、attach（枪口 / 瞄具 / 弹匣 / 握把）、playerSkills、bossSkills
    • 
      
  • 防具系统：helmetShells、helmetVisors、helmetEars、vestFibers、vestPlates、backpacks、chestRigs
    • 
      
  • 物品：consumables、nades、valuables
    • 
      
  • 角色与敌人：characters、enemyTypes、aiTypes、initialLoadout
    • 
      
  • 关卡与玩法：maps、tasks、chatLines、killStreakTiers、events、difficulty、killDrops
    • 
      
  • 高级：scripts（脚本钩子）、其他未归类数据（JSON 编辑器）
    • 
    


    
关于「复制 / 删除 / 新增」

    
    
      
  • 新增：会以当前类别默认字段创建一个空条目，ID 自动生成 new_xxx_1，请手动修改。
    • 
      
  • 复制：复制当前条目，ID 自动加 _copy 后缀，避免冲突。
    • 
      
  • 删除：直接删除当前条目，有二次确认。删除后按 Ctrl+Z 可撤销一次。
    • 
    


    
注意事项

    

      ⚠ 函数不会被 JSON 化。 脚本钩子（如 ASAKA.scripts.onTick）是真正的 JS 函数，本工具会以文本形式保留其源码并原样写回。如果函数源码里含注释，格式化时可能会丢失，建议重要脚本手动备份。
    

    

      ⚠ 不会自动加载。 本工具需要你手动选择 data.js 文件。因为浏览器的安全策略，除非你把它和 data.js 放在同一个本地服务器下，否则无法自动读取。
    

    

      ⚠ 保留原文件。 导出前请务必备份原 data.js。本工具会重新生成整个文件（除头部注释外），可能丢失手工添加的注释。
    


    
快捷键

    
    
      
  • Ctrl+S：源码预览
    • 
      
  • Ctrl+E：导出
    • 
      
  • Ctrl+Z：撤销上一次删除
    • 
      
  • Esc：关闭弹层
