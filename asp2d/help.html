01游戏概述

Asaka Straight Project 2D（简称 ASP2D）是一款以 Praze 世界观为背景的 2D 俯视撤离射击（Extraction Shooter）。你扮演一名人类队长， 也可以直接操控其他角色，在 Asaka 大陆的多个战区中搜索物资、击杀敌人， 并设法活着抵达撤离点。

游戏的核心特征是将设定集里的物理性机制——动能、护甲层级、Prazer 耦合能—— 全部落成可操作的玩法。它不是"扣血"式的射击游戏：每一发子弹都带着真实的焦耳数， 每一块护甲都有独立的耐久与穿透抗性，每个 Prazer 角色的每一次防护都在燃烧自己的耦合能。

🎯 物理伤害

子弹有质量、初速、距离衰减；护甲有层级、耐久、穿透阈值。

🐾 Prazer 耦合

兽耳角色的防护与技能都消耗耦合能，来源设定集真实公式。

🎒 深度背包

胸挂 / 口袋 / 背包 / 安全箱四容器 + 拖拽装备 + 配件拆装。

⚔ BOSS 战

三张地图各有独立 BOSS，拥有护盾、召唤、温压弹等技能。

🧠 动态 AI

视锥侦测、掩体选择、救援倒地队友、投掷物决策、拾取更优武器。

🌪 事件系统

物资空投、P 空间波动、沙尘暴——每一局都不一样。

阅 读 建 议
本手册按模块组织。新玩家建议按顺序读「基础操作 → 角色 → 伤害机制 → 撤离」； 老玩家可以直接跳到「Prazer 与耦合能」「护甲系统」查机制细节。

03对局模式

单人生存

没有 AI 队友。倒地后无法被救援，会直接判定失败。
适合：熟悉地图、练习、挑战。

双人队

你 + 1 名随机 AI 队友。倒地后队友可以前来救援。
适合：标准体验。

三人队

你 + 2 名 AI 队友。战术配合更好，但目标也更大。
适合：BOSS 战、高难地图。

队友从可玩角色池中随机抽取（不会与你自己重复），并自动继承该角色的武器与技能。

04地图介绍

尼珀斯尔工厂

西北工业区的一座旧化工厂。地图布满厂房、管道、集装箱，掩体密度高，中近距离交火为主。Boss 是尼珀斯尔领导（人类，外骨骼）。

  • 地形特点：室内走廊 + 屋顶平台 + 地下管道，三层立体作战空间。
  • 适合武器：突击步枪、冲锋枪、霰弹枪。
  • 潜在风险：狭窄通道里容易被大量敌人围堵。

边陲小镇

大陆南缘的荒漠小镇。开阔区域多，掩体稀散，中远距离交火为主。周期性出现沙尘暴，能见度骤降。Boss 是黑奈契（狼 Prazer，A=4）。

  • 地形特点：开阔街道、废墟、干涸河床，狙击点位非常多。
  • 适合武器：狙击枪、精确射手步枪、DMR。
  • 特殊机制：沙尘暴期间视野降低 45%，狙击镜效果减半。

大陆银行·地下研究所

大陆银行名义下的研究设施。走廊狭窄，房间密集，近距离突袭战。中立 Boss 是二里缘雪乃（猫 Prazer，A=10，大陆银行总经理）。

  • 地形特点：B1 层单一平面，实验室与储藏室交错。
  • 适合武器：冲锋枪、霰弹枪、手枪。
  • 雪乃是中立角色，如果好感度足够，可以在她那里办理存储与交易业务。
关 于 撤 离 点
每张地图有 4 个撤离点，位于四个角落。撤离点周围 20 米内如果有敌人存活，会显示为红色锁定状态，无法撤离——你必须先把周边清干净。

07武器系统

武器分为 手枪 / 冲锋枪 / 突击步枪 / 狙击枪 / 霰弹枪 / 轻机枪 / 榴弹发射器 七大类。 每把枪有口径、动能、穿透、射速、弹匣容量、换弹时间、散布、后坐、射程、初速、自动 / 半自动等属性。

武器分类与定位

手枪

副武器，近距离补枪。沙鹰穿甲不错但后坐极大。

冲锋枪

高射速、低穿透。室内清剿与近身遭遇战首选。

突击步枪

中距离万金油。AR-556 与 AK-762 差异在穿透与后坐。

狙击枪

中远距离精确打击。栓动高伤害，半自动持续压制。

霰弹枪

10 米内极端杀伤，超过 25 米基本等于装饰。

轻机枪

压制射击。弹链容量巨大但换弹极慢。

榴弹发射器

GM-94，4 发弹管。可混装高爆 / 温压弹。

典型武器

枪 械 关 键 属 性
  • 动能（J）：子弹出膛时的能量，决定基础伤害。
  • 穿透（pen）：与护甲等级做差，决定能否击穿及穿透程度。
  • 散布（spr）：每发子弹的随机偏移，受瞄准、静止、伤势影响。
  • 后坐（rec）：每发射击对玩家位置的推力，影响连发准度。
  • 射程（rng）：超过此距离动能开始快速衰减。
  • 初速（spd）：弹丸飞行速度，影响命中移动目标的提前量。

09配件系统

武器有四个配件槽：枪口 / 瞄具 / 弹匣 / 握把。拖拽背包里的配件到槽位即可安装。

槽位常见配件作用
枪口 消音器 / 补偿器 / 制退器 / 扩音器 消音降噪、减少后坐、或反其道增加动能
瞄具 机瞄 / 红点 / 全息 / 4倍 / 8倍 / 热成像 降低散布、提升射程、放大倍率
弹匣 扩容 / 快弹 / 弹鼓 / 轻弹 / 战术 提升弹匣容量或缩短换弹时间
握把 垂直 / 斜角 / 战术 / 脚架 降低后坐、提升连发稳定性
倍 镜 与 视 野
使用倍镜时（默认 Shift 或瞄准按钮），画面会放大，视野收窄。这是为了提高远距离精度，但也让你更难发现侧翼的敌人。装配 4 倍镜以上时，近战风险显著提升。

10护甲系统

护甲分五个独立槽位：头盔壳 / 面罩 / 耳机 / 纤维层 / 插板。每个槽位有独立等级（Lv0–Lv8）、耐久、能量容量。

槽位防护部位典型 Lv作用
头盔壳头部1–8防头部命中，被击穿则大量掉血
面罩面部2–8保护面部，防止爆头秒杀
耳机—2–8提升拾音范围、降低闪光弹效果
纤维层躯干1–8软质防护，吸收能量降低穿透
插板躯干2–8硬质防护，抵挡高穿透弹

护甲工作机制

  • 每块护甲都有 Lv 等级 和 能量容量（J/1%）。
  • 每次被命中时，护甲会按穿透差值吸收部分能量，剩余能量穿透到身体。
  • 护甲吸收能量后会按能量容量比例扣除耐久。耐久越低，减伤系数越低。
  • 纤维层和插板是两层独立吸收，插板先挡，纤维再兜底。
  • 插板被打坏可以用 陶瓷插板 / 护甲修理包 / 纳米修复仪 恢复，头盔和纤维层则不能修补。
穿 甲 机 制
穿透差值 = 子弹穿透 − 护甲等级。
≥ 3：几乎无视护甲（穿甲）
1 ~ 2：护甲减伤按比例削弱
0：护甲发挥完整效果
< 0：护甲减伤反而增强

11伤害机制

ASP 不采用"扣血"模型，而是基于 动能 → 护甲吸收 → 部位倍率 → HP 换算 的流程。

命中部位

部位权重伤害倍率说明
面部1.5%×3.4致命，通常一枪毙命
头部8.5%×2.0高伤害，被头盔挡下会减伤
胸部44%×1.0主要命中部位
腹部19%×1.05有概率触发流血
手臂8% × 2×0.72手臂断裂会提升散布
腿部5.5% × 2×0.85双腿断裂会大幅降低移速

能量公式

子弹动能 = ½mv²，随距离指数衰减 E(r) = E₀·exp(−1.15·(r/R)²)。 命中后先由耦合防护吸收（Prazer），再由护甲吸收，剩余能量按 E/系数 换算为 HP 伤害。

  • 普通人类身体系数：34
  • Prazer 身体系数：48（体型更坚韧）
  • 重装甲身体系数：42

部位损伤

四肢和躯干有独立的"部位血量"。部位被持续命中会进入 正常 / 轻伤 / 中伤 / 重伤 / 断裂 五种状态。

  • 手臂断裂 → 散布 ×1.8
  • 单腿断裂 → 移速 ×0.58
  • 双腿断裂 → 移速 ×0.32
  • 腹部重伤 → 持续流血（0.6 HP/s）

12Prazer 与耦合能

兽耳角色（凯特、玲娜）拥有 Prazer 耦合系统。这是设定集里"Prazer 通过与 P 空间耦合借力"的玩法落地。

耦合能槽

  • 游戏内统一显示为 100 点，但实际耦合能量由角色年龄与 Aselevel 决定。
  • 凯特：Q ≈ 22.31，每点游戏耦合能 = 0.2231 实际值。
  • 玲娜：Q ≈ 22.41，每点游戏耦合能 = 0.2241 实际值。
  • 每点耦合能代表的实际能量越大的角色，受同样攻击扣除的游戏内点数越少。

耦合防护（L1 / L2 / L3）

按住 1 2 3 或点击左下按钮，开启对应等级的防护。松开即关闭。

等级防护范围吸收率待机消耗
L1仅冷兵器100%0.8 / s
L2冷兵器 + 热兵器70%2.5 / s
L3所有武器（含激光）50%（激光 30%）5.0 / s

受击消耗

实际消耗的耦合能 ΔQ = ψ · E_抵消 · t_eff， 其中 ψ ≈ 0.00335791，t_eff = 0.5， E_抵消 为该防护等级下实际抵消的动能。

举例：凯特开 L2 被 5.56mm 步枪弹（1620J）命中，抵消 1134J，实际消耗约 1.90，游戏内扣除约 8.5 点。

恢复机制

  • 停止使用耦合能后，延迟 1 秒 开始恢复。
  • 若此前连续使用不超过 10 秒，恢复速率 3 点/秒。
  • 若此前连续使用超过 10 秒，恢复速率降为 1.5 点/秒。
  • 耦合能为 0 时，L1/L2/L3 全部失效，需要等恢复。
高 等 级 的 代 价
耦合强度（Aselevel）越高的 Prazer，能量消耗性价比越低，但上限更高。 长期开启 L3 会在几秒内耗尽耦合能——真实设定中这是在消耗自己的寿命。

Prazer 生理特征

  • 兽耳 / 覆耳羽 / 兽尾：极度敏感，被破坏后体能大幅下降。游戏中体现在低血量时的视觉效果和移动惩罚。
  • 信息素：设定中 Prazer 会释放崇高素 / 神圣素 / 感召素，对低等级 Prazer 有影响。本作保留了机制框架，实际表现以 BOSS 技能为主。
  • 虚妄素：仅少数 Prazer 能分泌。黑奈契的「虚妄素」技能会对周围敌人造成混乱效果。
  • 食量：设定中 Prazer 单日食量需求为 (3000 + e·ln A) 大卡，游戏中不直接体现。

20受伤与倒地

受伤视觉

  • 血量低于 80%：轻微画面模糊
  • 血量低于 60%：明显模糊 + 色度降低
  • 血量低于 40%：强模糊 + 红边
  • 血量低于 20%：极强模糊 + 灰化 + 红屏闪烁
  • 闪光弹命中：全屏白闪 1–4 秒
  • 进入火焰区：画面饱和 + 红色警告环

流血

腹部重伤有概率触发流血（0.6 HP/s）。流血不会自动停止，除非使用绷带 / 急救包 / 手术包。

倒地

  • 血量归零时先进入倒地状态，可以缓慢移动。
  • 倒地倒计时默认 30 秒。倒计时结束即死亡。
  • 队友可以在附近按救援按钮，读条 4 秒后把人救起。
  • 倒地期间再次被补刀会直接死亡（无二次倒地机会）。
  • 单人模式倒地会立即判定失败。
已 经 倒 过 一 次
被救起后再倒地，会直接死亡，不再进入倒地状态。第二次倒地就是最后一次。

23训练场

从主菜单点击「训练场」进入。这是一个无压力测试环境，没有敌人主动攻击你，只有若干假人靶子。

训练设置面板

  • 主武器 / 副武器：任意切换所有武器，选择弹种。
  • 假人护甲：单独设置假人的头盔壳、面罩、纤维层、插板等级，用来测试穿甲效果。
  • 无限子弹：默认开启。
  • 重置假人：一次性恢复所有假人的血量与护甲。

TTK 显示

命中假人时，屏幕上会显示 TTK（Time To Kill，击杀耗时）。 从第一次命中到击杀的时间越短，说明你的配置越有效。 假人死后 3.5 秒会自动复原，可以反复测试。

敌人状态面板

靠近假人时会显示一个面板，列出当前假人的血量、命中部位、护甲剩余。用来精确评估不同弹种的实际效果。

声纹条带详解

屏幕底部的条带是 ASP 的听觉系统。它把周围声音按方向投影到一条水平轴上： 左侧 = 身后偏左，中间 = 正前方，右侧 = 身后偏右。 白色竖条表示脚步、换弹等普通声音；红色竖条表示枪声、爆炸等高威胁声音。 佩戴越好的耳机，拾音范围越大、分辨率越高。

25常见问题

Q1：为什么我打中了敌人，伤害数字那么小？

检查两件事：（1）你用的弹种是否穿透足够？（2）命中部位是否被护甲挡住？ 如果提示里有"甲-XX%"或"穿甲!"字样，说明护甲起作用了。换更高穿透的弹种，或者瞄准裸露部位（手臂、腿）。

Q2：为什么我的耦合能一下子耗光了？

耦合防护是持续消耗的。L3 每秒消耗 5 点，20 秒就能清空。 建议只在高威胁时刻开启，平时关掉让耦合能恢复。 记住：连续使用不超过 10 秒恢复速率是 3/秒，超过就降到 1.5/秒。

Q3：撤离点一直显示红色，怎么办？

撤离点周围 200 单位内有敌人存活。清掉它们——包括倒地的（有些会自己被队友救起）。

Q4：队友倒地了，怎么救？

走到队友身边（70 单位内），屏幕会出现「按住救 XXX」按钮。 按住几秒完成救援，队友以 40% 血量起身。注意：队友倒地期间被再次命中会直接死亡。

Q5：为什么敌人被打中不倒，反而逃了？

敌人有"倒地→救援"机制。如果你没能在短时间内补刀，周围的敌人会来把他救起。 如果想要确认击杀，需要再次命中倒地目标。

Q6：为什么我的武器没配件？

配件需要在背包里手动安装。点击武器 → 打开漂浮面板 → 拖入配件。 初始装备里已经预装了一部分配件，但收集到的配件要自己装。

Q7：BOSS 打不过怎么办？

建议：（1）提高难度前先练好基本操作；（2）带够穿甲弹；（3）带足医疗与护甲修补；（4）单人模式下也可以慢慢磨——BOSS 不会主动跑出地图。

Q8：手机能玩吗？

可以。移动端和 PC 端在主菜单「平台」里切换，切换后 HUD 会自动重排。 触屏用户会看到虚拟摇杆和右侧按钮组。

Q9：能把数据保存下来吗？

目前 ASP2D 没有持久化存档。一局结束即结算，重新开始是新的一局。 安全箱里的物品能在撤离失败时保留，但不会跨局继承。
